# Тренажёры по русскому языку

Сайт для 10 класса и подготовки к ЕГЭ-2026. Работает на GitHub Pages без сервера и регистрации: ученик открывает ссылку и занимается с телефона или компьютера.

## Что внутри

| Тема | Файл | Задание ЕГЭ |
|---|---|---|
| Ударения (орфоэпический список ФИПИ-2026, 221 слово) | `udareniya.html` | 4 |
| Паронимы (список паронимов ФИПИ-2026) | `paronimy.html` | 5 |
| Лишнее слово и сочетаемость | `leksicheskie-normy.html` | 6 |
| Формы слов | `formy-slova.html` | 7 |
| Гласные в корне | `korni.html` | 9 |
| Приставки | `pristavki.html` | 10 |
| Суффиксы | `suffiksy.html` | 11 |
| Окончания глаголов и суффиксы причастий | `okonchaniya.html` | 12 |
| НЕ и НИ | `ne-ni.html` | 13 |
| Слитно, раздельно, через дефис | `slitno-defis.html` | 14 |
| Н и НН | `n-nn.html` | 15 |
| Пре или при: словарные слова | `pre-pri-slovar.html` | — |

В каждой теме пять вкладок:

- **Учить** — случайное слово, мгновенная проверка и объяснение. Слова с ошибками попадаются чаще, пока не будут решены дважды подряд.
- **Диктант** — 10, 20, 30 или все задания, проверка в конце. Во многих темах есть диктант на слух: браузер читает слово, ученик пишет его целиком.
- **ЕГЭ** — задание в формате КИМ: ряды слов, поиск ошибки, цифры в скобках, выбор верных ударений, слова со скобками вроде «(не)знал».
- **Список** — все слова с ответами, поиском и отметкой «мои ошибки».
- **Правила** — теория и исключения.

## Как опубликовать (один раз)

1. Зарегистрируйтесь на [github.com](https://github.com) и создайте репозиторий: **New repository**, имя например `russkiy`, тип **Public**.
2. Загрузите все файлы из этого архива: **Add file → Upload files**, перетащите содержимое папки целиком (вместе с папками `assets`, `tools`, `templates`, `.github`), **Commit changes**.
   Папка `.github` начинается с точки и может быть скрыта. Если её не видно, включите показ скрытых файлов или создайте файл `.github/workflows/pages.yml` вручную через **Add file → Create new file** и вставьте туда содержимое.
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь зелёной галочки (1–2 минуты).
5. Сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/russkiy/`. Эту ссылку и нужно отправить ученикам.

## Как добавить новую тему

Загрузите новый HTML-файл в корень репозитория. При каждой загрузке GitHub сам пересоберёт список тем (`topics.js`) и обновит сайт. Шаблон и подробная инструкция — в [templates/README.md](templates/README.md).

Если в настройках выбран режим **Deploy from a branch** вместо **GitHub Actions**, список тем сам не обновится. Тогда после загрузки нового файла запустите на компьютере `node tools/build-topics.js` и загрузите получившийся `topics.js`.

## Где хранится прогресс

Только в браузере ученика (`localStorage`). На сервер ничего не отправляется, учитель не видит результаты автоматически. Поэтому:

- на главной странице есть предупреждение, что прогресс пропадёт при очистке браузера, в режиме инкогнито и на другом устройстве;
- сайт просит браузер не удалять данные (Chrome и Firefox обычно соглашаются);
- на iPhone Safari стирает данные сайтов, которые не открывали 7 дней. Помогает добавить сайт на экран «Домой»;
- кнопка **«Сохранить в файл»** скачивает прогресс, **«Загрузить из файла»** возвращает его — так можно перенести занятия на другое устройство;
- **«Отчёт для учителя»** собирает текст со сводкой по всем темам и списком ошибок. Ученик копирует его и отправляет учителю.

## Устройство сайта

```
index.html            главная: список тем, прогресс, отчёт
topics.js             список тем (создаётся автоматически)
*.html                темы
assets/site.css       общий дизайн, цвета тем, светлая и тёмная схема
assets/core.js        хранение прогресса, экспорт и импорт
assets/trainer.js     движок тренажёра: все режимы
assets/fonts/         шрифты Literata и Golos Text (лицензия OFL)
tools/build-topics.js сборка topics.js из meta-тегов страниц
.github/workflows/    автоматическая публикация на GitHub Pages
templates/            шаблон новой темы и инструкция
```

Сайт можно открыть и без интернета: скачайте папку и откройте `index.html` в браузере.
