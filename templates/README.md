# Как добавить новую тему

Каждая тема — это один HTML-файл в корне сайта (рядом с `index.html`). Главная страница сама находит все такие файлы и показывает их списком.

## Способ 1. Скопировать шаблон

1. Скачайте `templates/new-topic.html`, переименуйте латиницей без пробелов: `ne-ni.html`, `suffiksy.html`.
2. Откройте в любом текстовом редакторе и поменяйте:
   - теги `<meta name="topic:...">` — название, описание, номер задания, раздел, цвет;
   - массив `ITEMS` — слова с пропуском `#`;
   - блок `<template id="rules">` — правила.
3. На GitHub: **Add file → Upload files**, перетащите файл, нажмите **Commit changes**.
4. Через 1–2 минуты тема появится на главной странице.

## Способ 2. Попросить Claude

Скопируйте текст ниже, допишите тему и список слов (или приложите фото таблицы, как было с ПРЕ/ПРИ), и отправьте вместе с файлом `templates/new-topic.html`:

> Сделай новую тему для моего сайта-тренажёра по русскому языку. Возьми за основу приложенный шаблон `new-topic.html`: сохрани подключение `assets/site.css`, `assets/core.js`, `assets/trainer.js` и вызов `Trainer.start`, поменяй только meta-теги, данные и правила.
> Тема: … (например, «НЕ с разными частями речи, задание 13 ЕГЭ»).
> Слова: … (или «подбери сам 80–120 слов по школьной программе 10 класса»).
> Проверь каждое слово по правилам, к каждому дай короткое пояснение, раздели на разделы для фильтров и выбери подходящий режим «Как на ЕГЭ».
> Пришли готовый HTML-файл.

Получившийся файл загрузите на GitHub, как в способе 1.

## Своя страница без шаблона

Подойдёт любой HTML-файл: игра, шпаргалка, тест другого формата. Чтобы он появился на главной, добавьте в `<head>` хотя бы:

```html
<meta name="topic:id" content="moya-stranitsa">
<meta name="topic:title" content="Моя страница">
<meta name="topic:group" content="Другое">
```

Если мета-тегов нет, страница всё равно появится в разделе «Другие темы» под названием из `<title>`.

Чтобы спрятать страницу с главной, добавьте `<meta name="topic:hidden" content="1">` или начните имя файла с `_`.

## Настройки темы

| Мета-тег | Что значит |
|---|---|
| `topic:id` | Уникальный id латиницей. По нему хранится прогресс. **Не меняйте после публикации**, иначе прогресс учеников по теме обнулится. |
| `topic:title` | Название на карточке. |
| `topic:desc` | Одно предложение под названием. |
| `topic:group` | Раздел на главной. Темы с одинаковым разделом стоят вместе. |
| `topic:task` | Номер задания ЕГЭ. Показывается значком «ЕГЭ №…» и связывает тему с картой заданий. |
| `topic:grade` | Класс. Если нет номера задания, на карточке будет «10 класс». |
| `topic:order` | Порядок: чем меньше число, тем выше. Удобно ставить номер задания × 10. |
| `topic:accent` | Цвет темы: `violet`, `teal`, `blue`, `rose`, `amber`, `plum`, `olive`. Его же пишут в `<html data-accent="...">`. |
| `topic:count` | Сколько заданий в теме — показывается, пока ученик не начал. |
| `topic:unit` | Как называть задания на карточке, три формы через черту: `слово\|слова\|слов`. По умолчанию — «задание». |

## Настройки `Trainer.start`

| Поле | Что значит |
|---|---|
| `id` | Тот же, что в `topic:id`. |
| `kind` | `'choice'` — выбрать вариант на месте `#`; `'stress'` — нажать на ударную гласную. |
| `items` | Задания. Для `choice`: `{ t, a, o, c, g, n, h }`. Если в `t` нет `#`, ответ — слово из самого текста (так сделано «лишнее слово»). Для `stress`: `{ w: 'аэропОрты', n, c }` — ударная гласная прописная. |
| `options` | Варианты по умолчанию, если у задания нет своего `o`. |
| `optionLabels` | Подписи под кнопками: `{ 'е': 'ПРЕ' }`. |
| `categories` | Разделы для фильтров: `[{ key, label }]`. У задания — поле `c`. |
| `groups` | Объяснения правил: `{ ключ: { h: 'заголовок', p: 'текст' } }`. У задания — поле `g`. |
| `rulesFromGroups` | `true` — на вкладке «Правила» показать группы со всеми их словами. |
| `rules` | Правила списком: `[{ h, p, ex: [...], trap: [...], trapLabel }]`. |
| `ear` | `true` — диктант на слух (браузер читает слово вслух). |
| `exam` | Режим «Как на ЕГЭ»: `rows`, `odd`, `digits`, `select`, `stressSelect` (см. комментарии в шаблоне). `select` — ряды по `per` слов, верные те, где у всех ответ `pick` (задания 13, 14). |
| `optionNames` | Подписи вариантов вместо самого значения: `{ '': 'слитно', '\u00a0': 'раздельно', '-': 'через дефис' }`. |
| `paren` | `true` — показывать пропуск как в КИМ: «(не)знал», «(в)течение». С `gapText` задаётся текст в скобках, если слева от `#` пусто. |
| `autoNext` | Переходить к следующему слову после верного ответа автоматически. По умолчанию — да для букв и ударений, нет для слов. |
| `source` | Откуда взят список — показывается внизу страницы. |
